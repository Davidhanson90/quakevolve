# AGENTS

This repository is a **demo app** (not an npm library).

## Scope

- App source: `src/`
- Entry: `index.html` + `src/main.ts`
- Build output: `dist/` (generated by Vite)
- Catalog snapshot: `public/data/earthquakes.json`

## Rules

1. Do not edit `dist/` directly.
2. Keep learning pure TypeScript — genetic algorithm only (no TF.js / remote ML APIs).
3. Preserve Lit custom element tags `qv-playground`, `qv-fitness-chart`, and `qv-quake-map` unless intentionally changing API.
4. Vite `base` must stay `/quakevolve/` so GitHub Pages works at `https://davidhanson90.github.io/quakevolve/`.
5. Keep the educational disclaimer prominent in README and in-app copy — this is **not** operational earthquake forecasting.
6. Run `npm run build:verify` before proposing completion.
7. Do not npm-publish this package.

## Coverage

- Vitest coverage thresholds apply to `src/data/**`, `src/features/**`, `src/model/**`, and `src/ga/**`.
- Lit UI under `src/ui/**` is excluded from coverage thresholds.
